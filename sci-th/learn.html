หน่วยที่ 3 — แรงกับการเคลื่อนที่และแม่เหล็ก

ตัวชี้วัด ว 2.2 ป.3/1 – ป.3/4 · สอนครบทุกเรื่องที่ออกสอบ

① แรงกับการเคลื่อนที่ ② แรงสัมผัส / ไม่สัมผัส ③ สารแม่เหล็ก ④ ขั้วแม่เหล็ก ⑤ สรุปก่อนสอบ

1 แรงทำอะไรกับวัตถุได้บ้าง

แรง คือการ ดึง หรือ ผลัก ที่เรากระทำต่อวัตถุ · แรงทำให้เกิดผลได้ 2 แบบใหญ่ ๆ

① เปลี่ยนการเคลื่อนที่ ของหยุด → วิ่ง · ของวิ่ง → หยุด · เร็วขึ้น · ช้าลง · เปลี่ยนทิศ
② เปลี่ยนรูปร่าง ปั้นดินน้ำมัน · ก่อกองทราย · ดัดลวด — ของอยู่ที่เดิม แค่รูปร่างเปลี่ยน

ข้อสอบชอบเอา 2 อย่างนี้มาหลอกกัน ถ้าถามว่า "ทำให้เคลื่อนที่" ต้องเลือกข้อที่ของย้ายที่จริง ๆ

🔑 หัวใจของหน่วยนี้ — ทิศของแรงบอกผลลัพธ์
ออกแรงยังไงผลที่เกิดตัวอย่างในข้อสอบ
ทิศเดียวกับที่วัตถุวิ่ง
(ดันตามหลัง)		 เร็วขึ้น ผลักท้ายรถของเล่นที่กำลังวิ่ง · ผลักม้าหมุนตามทางที่หมุน
ทิศตรงข้ามกับที่วัตถุวิ่ง
(ต้านไว้)		 ช้าลง / หยุด เอามือจับรถที่วิ่งมา · รับลูกฟุตบอลที่เพื่อนเตะมา
ทิศข้าง ๆ เปลี่ยนทิศ ตบลูกวอลเลย์บอลข้ามตาข่าย
ของหยุดนิ่งอยู่ แล้วออกแรง เริ่มเคลื่อนที่ เตะบอลส่งเพื่อน · ลากโต๊ะ
ลองคิดดู

"ซี รับลูกฟุตบอลที่เพื่อนเตะมา" — ลูกบอลกำลังวิ่งมา ซีออกแรงต้าน → ลูกบอลหยุดนิ่งในมือ ✅

"ดี ตบลูกวอลเลย์ข้ามตาข่าย" — ลูกวิ่งมาแล้วเปลี่ยนทิศวิ่งต่อ ไม่ได้หยุด ❗

2 แรงสัมผัส กับ แรงไม่สัมผัส

คำถามเดียวที่ต้องถาม

“ต้องแตะถึงกันไหม ถึงจะออกแรงได้?”

แตะ = แรงสัมผัส ดึง · ผลัก · ลาก · เข็น · เตะ · ถีบ · ปั้น · เปิดหน้าต่าง
ไม่ต้องแตะ = แรงไม่สัมผัส แรงแม่เหล็ก · แรงโน้มถ่วง (ของตกลงพื้น) · แรงไฟฟ้าสถิต

🎮 ลองแยกดู — แตะกดดูว่าข้อไหนเป็นแบบไหน

เลือกให้ครบทุกข้อ ตอบแล้วรู้เฉลยทันที

⚠️ จุดที่เด็กพลาดบ่อยที่สุด

แม่เหล็กดูดตะปู → คนมักตอบว่า "สัมผัส" เพราะสุดท้ายตะปูไปติดแม่เหล็ก

แต่ให้ดูที่ตอนเริ่มออกแรง — ตอนที่ยังห่างกัน แม่เหล็กก็ดูดแล้ว จึงเป็น แรงไม่สัมผัส เสมอ

3 สารแม่เหล็ก — อะไรที่แม่เหล็กดูดได้

กฎเหล็ก (ตามชื่อเลย)

แม่เหล็กดูดได้เฉพาะ สารแม่เหล็ก คือ เหล็ก · นิกเกิล · โคบอลต์ เท่านั้น

ของที่เจอในข้อสอบและทำจากเหล็ก: ตะปู · เข็มหมุด · เข็มเย็บผ้า · เข็มกลัด · ลวดเย็บกระดาษ · ลวดเสียบกระดาษ · กรรไกร · ลูกกุญแจ

ของที่ดูดไม่ขึ้น: ยางลบ · กระดาษ · ตะเกียบไม้ · เส้นด้าย · พลาสติก · แก้ว

⚠️ โลหะ ≠ สารแม่เหล็ก

ทองคำ · เงิน · ทองแดง · อะลูมิเนียม เป็นโลหะก็จริง แต่แม่เหล็กดูดไม่ขึ้น — อย่าเห็นว่าเงาวาวแล้วตอบว่าดูดได้ทันที

🃏 การ์ดพลิก — ทายก่อนแล้วค่อยกดดูเฉลย

4 ขั้วแม่เหล็ก — เรื่องที่ออกสอบเยอะที่สุด

🔑 ท่องให้ขึ้นใจ 3 ข้อนี้ ทำได้เกือบครึ่งข้อสอบ
  1. แม่เหล็กมี 2 ขั้ว คือ ขั้วเหนือ (N) กับ ขั้วใต้ (S) — ไม่ใช่ขั้วบวกขั้วลบ (นั่นคือถ่านไฟฉาย)
  2. ขั้วเหมือนกัน → ผลักกัน · ขั้วต่างกัน → ดึงดูดกัน
  3. แม่เหล็กแท่งเดียวกัน ปลายสองข้างต้องต่างขั้วกันเสมอ (ข้างหนึ่ง N อีกข้างต้อง S)
🎯 เทคนิคทำข้อรูปแม่เหล็กให้ถูกทุกข้อ

มองแค่ 2 ตัวอักษรที่อยู่ติดช่องว่างตรงกลาง — ตัวริมนอกสุดไม่ต้องสนใจเลย

ตรงกลาง N ↔ S = ต่างกัน → ดึงดูด

ตรงกลาง N ↔ N = เหมือนกัน → ผลัก

🎮 เครื่องลองแม่เหล็ก — กดสลับขั้วดูเลย

กดปุ่มเพื่อพลิกแท่งแม่เหล็ก แล้วดูว่าผลเปลี่ยนไหม

แบบที่ 1 — โจทย์ให้ขั้วไม่ครบ ต้องเติมเอง

ใช้กฎข้อ 3 — ปลายสองข้างของแท่งเดียวกันต้องต่างกัน

เช่น แท่งขวาเขียนไว้ว่าปลายขวาเป็น S → ปลายซ้ายต้องเป็น N แน่นอน แล้วค่อยเอา N ไปเทียบกับปลายของแท่งซ้าย

แบบที่ 2 — แม่เหล็ก 2 แท่งดูดติดกันแล้ว แบ่งเป็น 4 ช่อง

ใช้ 2 กฎพร้อมกัน แล้วลองสมมติ:

  1. B กับ C ติดกันได้ → ต้องต่างขั้ว
  2. A ต่างจาก B · C ต่างจาก D (แท่งเดียวกัน)
  3. สมมติ A = เหนือ → B = ใต้ → C = เหนือ → D = ใต้
  4. ได้ว่า A กับ C เป็นขั้วเดียวกัน และ B กับ D เป็นขั้วเดียวกัน เสมอ
แบบที่ 3 — แขวนแม่เหล็กให้หมุนอิสระ

แม่เหล็กจะหมุนจนหยุดในแนว เหนือ–ใต้ เสมอ โดยขั้วเหนือชี้ทิศเหนือ และขั้วใต้ชี้ทิศใต้

เพราะโลกเราเป็นแม่เหล็กขนาดยักษ์ — นี่คือหลักการของเข็มทิศ

ทำซ้ำกี่รอบก็ได้ผลเหมือนเดิมทุกครั้ง ถ้าไม่เหมือนเดิม เข็มทิศก็ใช้ไม่ได้แล้ว

⚠️ ข้อที่ยากที่สุดในชุดนี้ — "ดึงดูดกัน สรุปได้ว่าอะไร"

แม่เหล็กเข้าใกล้ วัตถุ A แล้วดึงดูดกัน → A เป็นอะไรได้บ้าง

✅ เป็นได้ 2 อย่าง — เป็นเหล็ก ก็ได้ หรือเป็นแม่เหล็กที่หันขั้วต่างกันเข้ามาก็ได้ → ต้องตอบข้อที่พูดถึงทั้งสองแบบ

แต่ถ้าโจทย์บอกว่า ผลักกัน → ฟันธงได้เลยว่า A ต้องเป็นแม่เหล็ก เพราะเหล็กธรรมดาไม่มีวันผลัก มีแต่ถูกดูดอย่างเดียว

5 สรุปก่อนสอบ — อ่านแผ่นเดียวจบ

เจอคำนี้ในโจทย์ให้นึกถึง
ทิศเดียวกัน / ดันตามหลังเร็วขึ้น
รับ / จับ ของที่วิ่งมาหยุดนิ่ง
ตบ / ปัด ของที่วิ่งมาเปลี่ยนทิศ (ไม่ได้หยุด)
ปั้น · ก่อ · ดัดเปลี่ยนรูปร่าง ไม่ใช่เคลื่อนที่
แม่เหล็ก · ของตกลงพื้นแรงไม่สัมผัส
มือ/เท้าแตะของแรงสัมผัส
ยางลบ · กระดาษ · ไม้ · ด้าย · พลาสติกแม่เหล็กดูดไม่ขึ้น
ผลักกันได้ต้องเป็นแม่เหล็กทั้งคู่
N เจอ N หรือ S เจอ Sผลัก
N เจอ Sดึงดูด
แขวนแล้วปล่อยชี้แนวเหนือ–ใต้ เหมือนเข็มทิศ
อย่าลืม 2 กับดักนี้

① ข้อที่ถามว่า "ข้อใดไม่ถูกต้อง" — ในชุดนี้มี 2 ข้อ (ข้อ 7 กับ ข้อ 20) อ่านโจทย์ให้จบก่อนเลือก

② ขั้วแม่เหล็กคือ N–S ไม่ใช่บวก–ลบ · และ ขั้วต่างกันดึงดูด ไม่ใช่ผลัก
