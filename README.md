## 🚦 ระบบที่ทำให้ครูรู้ว่าน้องอยู่จุดไหน

ออกแบบมาสำหรับ**สอนออนไลน์ให้น้อง 2 คนพร้อมกัน** โดยที่ครูไม่ต้องเดาว่าใครติดตรงไหน

### 1. แถบเลขข้อ — เห็นภาพรวมใน 1 วินาที

อยู่ด้านบนสุดของหน้าแบบฝึกหัด **ติดหนึบไม่เลื่อนหาย** ตอนน้องแชร์หน้าจอ ครูมองแวบเดียวก็รู้หมด

| สี | ความหมาย |
|---|---|
| ⬜ เทา | ยังไม่ทำ — บอกว่าน้องทำถึงข้อไหนแล้ว |
| 🟩 เขียว | ตอบถูก |
| 🟥 แดง | ตอบผิด |
| 🟧 ส้ม | น้องกดขอให้ครูอธิบาย |

**กดที่เลขข้อได้** จะกระโดดไปข้อนั้นทันที — ใช้ตอนจะชวนคุยเรื่องข้อไหนก็ได้

### 2. ปุ่ม 🙋 "ติดข้อนี้ ขอครูอธิบาย"

มีอยู่ทุกข้อ น้องกดแล้วข้อนั้นจะเด้งขึ้นไปอยู่ใน**กล่องแจ้งครู**ด้านบน
ครูเห็นทันทีโดยน้องไม่ต้องพูดขัดจังหวะ

### 3. นาฬิกาจับเวลา

- กด **⏱ ตั้งเวลา** เพื่อกำหนดเวลาทำ เช่น 20 นาที (นับถอยหลัง เหลือ 2 นาทีเปลี่ยนเป็นสีเหลือง หมดเวลาเป็นสีแดง)
- ใส่ **0** = ไม่นับถอยหลัง แค่จับเวลาที่ใช้เฉย ๆ
- ปุ่ม **⏸ พัก** ใช้ตอนหยุดอธิบายกลางคัน เวลาจะไม่เดิน

### 4. จับเวลาทีละข้อ — จุดที่ดีที่สุดของระบบนี้

ระบบจับเวลาว่าแต่ละข้อน้องใช้เวลาเท่าไร พอทำเสร็จจะบอกว่า **ข้อไหนใช้เวลานานผิดปกติ**

> นี่คือ**จุดที่น้องลังเล** ซึ่งควรทบทวนซ้ำ **แม้จะตอบถูกก็ตาม**
> เพราะตอบถูกเพราะเดาได้ กับตอบถูกเพราะเข้าใจจริง ไม่เหมือนกัน

### 5. 📱 QR code → ครูส่องแล้วเห็นรายงานทันที

**น้องไม่ต้องคัดลอกอะไร ไม่ต้องพิมพ์อะไรเลย** — พอทำครบทุกข้อ
หน้าจอจะขึ้น **QR code** ค้างไว้ให้เอง

ครูแค่**เปิดกล้องมือถือส่องที่จอ** (ส่องจากจอที่น้องแชร์มาได้เลย ไม่ต้องเดินไปหา)
แล้วกดลิงก์ที่เด้งขึ้นมา → `teacher.html` จะเปิดพร้อมรายงานเต็มทันที:

- คะแนนรวม + **แยกตามเรื่อง** (บอกเลยว่าเรื่องไหนต้องสอนซ้ำ)
- ตาราง**ทีละข้อ** — ถูก/ผิด · เวลาที่ใช้ · เฉลย
- **แถวแดง** = ตอบผิด · **แถวเหลือง** = ใช้เวลานานผิดปกติ
- รายการข้อที่กดขอความช่วยเหลือ

ถ้า QR ดูเล็กไปตอนแชร์จอ ให้น้องกด **🔍 ขยายให้ใหญ่ขึ้น** จะเด้งเต็มจอ ส่องง่ายขึ้นมาก

**น้อง 2 คนใช้คนละเครื่อง ใส่ชื่อคนละชื่อ** คะแนนและเวลาแยกกันสนิท
ครูส่อง QR ทีละคนเพื่อดูรายงานของแต่ละคนได้

> **ทางสำรอง** ถ้าส่องไม่ติด ในหน้าสรุปผลมีหัวข้อพับไว้ว่า *“ส่องไม่ติด? ใช้ลิงก์แทนก็ได้”*
> กด **คัดลอกลิงก์** วางในแชท ครูกดลิงก์ก็เห็นรายงานเหมือนกัน
>
> ⚠️ **QR จะใช้ได้ก็ต่อเมื่ออัปเว็บขึ้น GitHub Pages แล้ว** เพราะ QR เก็บลิงก์ของเว็บไว้ข้างใน
> ถ้าเปิดจากไฟล์ในเครื่อง (`file://`) หน้าสรุปผลจะบอกและให้คัดลอกรหัสแทนโดยอัตโนมัติ

## วิธีใช้สอน (ลำดับที่แนะนำ)

1. **ครูเปิดหน้าสอนแล้วแชร์จอ** — สอนไล่ไปทีละหัวข้อตามหมายเลข (มีปุ่มกระโดดหัวข้อด้านบน)
2. **ให้น้องเปิดหน้าแบบฝึกหัดในเครื่องตัวเอง** แล้วแชร์จอกลับมาให้ครูดู
3. ครูดูแถบเลขข้อ เห็น**แดง**หรือ**ส้ม**ตรงไหนก็เข้าไปอธิบายข้อนั้น
4. ทำครบแล้ว **QR จะขึ้นเอง** — ครูส่องด้วยกล้องมือถือ รายงานเต็มเปิดขึ้นบนเครื่องครูทันที
5. เรื่องที่ได้ต่ำกว่า 60% → กลับไปอ่านหน้าสอนเรื่องนั้น แล้วกด **🔁 ทำเฉพาะข้อที่ผิดอีกรอบ**

> **ถ้าน้อง 2 คนทำไม่เท่ากัน** — คนที่เสร็จก่อนกดปุ่ม 🔁 ทำข้อที่ผิดซ้ำได้ จะได้มีอะไรทำระหว่างรออีกคน
